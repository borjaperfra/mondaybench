## CEO BRIEFING

**Subject:** Incident Status Update — Batch API (INC-2026-1109-01)
**Time:** 14:20 UTC
**Board Call Prep:** 15:00 UTC

**Executive Summary**
The Batch API experienced elevated error rates (502s) starting at 11:42 UTC today. The issue was isolated to one of our two worker fleets (fleet-a). A mitigation was applied at 12:58 UTC by shifting all traffic to the healthy fleet (fleet-b). Error rates have normalized to baseline levels (0.3–0.4%). The incident is currently in a 90-minute verification window to confirm stability before formal resolution.

**Key Facts for Board Call**
*   **Impact:** 7 out of 9 Batch API customer accounts experienced failures. Total failed requests were approximately 17,600 out of ~50,800 total Batch requests in the incident window (approx. 35% failure rate for affected accounts). Other API surfaces (Inference, Embeddings, Files) were unaffected.
*   **Root Cause:** Not yet established. Two hypotheses remain:
    1.  A recent deployment (`r3`) lowered database connection pool limits, which may have caused queueing under high load.
    2.  A spike in traffic from one customer (Wonka Industries) overwhelmed the fleet.
    *Note: The deployment also affected the healthy fleet, so the root cause is likely an interaction between the config change and specific load patterns on fleet-a.*
*   **Resolution Timeline:** Verification window closes at 14:30 UTC. If stable, we expect full resolution and fleet-a return to service by ~16:00 UTC.
*   **Customer Relations:** Contoso, an enterprise customer with an SLA contract, has been notified. We are tracking their potential SLA credit eligibility. Other affected customers are being handled via support tickets.
*   **Security Note:** An unrelated security finding (over-permissioned database role) was discovered during triage. It is being tracked separately (Ticket SEC-411) and did not contribute to this incident.

**Recommended Talking Points**
*   "We had a partial outage in our Batch API service due to a configuration change interacting with high traffic on one server fleet. We successfully mitigated it within an hour by shifting traffic to a healthy fleet."
*   "We are currently verifying stability. Full resolution is expected by early afternoon."
*   "We are managing customer communications, including SLA discussions with Contoso. No data loss or security breach occurred."
