## CEO BRIEFING

We are currently managing an incident affecting the Batch API that began at 11:42 UTC today. 

The issue was mitigated at 12:58 UTC by rerouting all Batch API traffic away from the affected worker fleet (fleet-a) to a healthy fleet (fleet-b). Since the cutover, error rates have dropped significantly and are currently holding between 0.3% and 0.4%. 

We are currently in a 90-minute verification window to ensure stability; this window closes at 14:30 UTC. If it closes without further issues, we expect to have the affected fleet back in rotation by approximately 16:00 UTC.

The root cause is not yet established. We are investigating two main hypotheses: a recent change to database connection pool settings in a software release, and concentrated load on the affected fleet.

Impact is limited to the Batch API; all other services (Inference, Embeddings, Files) are operating normally. Seven customer accounts experienced failures. Contoso is the only affected customer with an SLA that carries service credits.
